## 5. Feedback / improvements (game + UX)

- **F1 · P1 — Commentary pipeline too slow for its timeout.** LLM+TTS ≈ 25 s vs `TIMEOUT_MS=20_000` in `opencode.ts`. Fix: raise to 45 s, or parallelize the 4 TTS calls (they're independent — biggest win), or stream. This alone cost ~14 of 17 broadcasts.
- **F2 · P2 — Boundaries arriving during an in-flight generation are consumed and never retried** (`fresh[fresh.length-1]` in TvCommentary). Queue or retry missed boundaries after the current playback.
- **F3 · P2 — Spectator label bug**: TV shows "Hugo_V - Dutch, Selling, enthusiastic, happy" (voice-library label) where the persona name ("Kick") should be.
- **F8 · P2 — Grounding**: prompt should forbid inventing events ("ze gooien niks") — add "use ONLY the facts in the turn lines; if unsure, ask about listed facts".
- **F9 · P3 — Empty outlook segment** on boundary 16 (parse fallback / model truncation) — validate and regenerate the missing segment.
- **F4 · P3 — Dead dart on blank land is invisible** in the war log (strict founding is a core rule; a "wasted a dart on blank 5" line would teach it).
- **F5 · P3 — Misses not logged** either; 3-miss turns leave no trace in the feed.
- **F6 · P3 — End-state dart display "51/0"** (thrown/remaining) looks broken on the podium; show "51/51" or just the budget.
- **F7 · P3 — TV stuck on "Laden…" while the tab is backgrounded** (`document.hidden` gate + background timer throttling). Fine for a real cast tab, but worth a hint in the UI ("keep this tab visible") or a wake-on-focus immediate poll.
- **F10 · P3 — Smallest preset (51 darts ≈ 17 turns/player) is long for casual sprint nights**; consider a ~24-dart band.
- **F11 · Design question — Shanghai bonus carried into the Altar visit** (turn 7 got 3+1 darts while dead). Spec is silent; decide and document.
- **F12 · Design question — A denied duel ends the dead player's visit immediately** (remaining altar darts not thrown). Matches "restarts the bull hunt", but confirm intended.
- **Praise**: curated options engine (`conquest-options.ts`) is smart and accurate — kill-shots, leader-attacks and continent-denial labels all matched the real board state; the "gooit" Dutch copy fix is live.
